# Skill de extração de cartão: Nubank

Use estas orientações somente para faturas que identifiquem Nubank. As amostras Nubank analisadas até agora são CSVs de movimentação de conta, não faturas de cartão. Aplique a [skill genérica de cartão](generica-cartao.md) e não infira estrutura, datas ou convenções de fatura a partir da skill de extrato Nubank.
